# RemoteHub - 올인원 웹 원격 접속 게이트웨이 (VNC · RDP · SSH)

웹 브라우저 하나로 다수의 **VNC**, **RDP (Windows)**, **SSH 터미널** 서버를 등록하고 관리하며, 별도의 클라이언트 프로그램 설치 없이 즉시 접속할 수 있는 초경량 올인원 웹 게이트웨이 솔루션입니다.

---

## 🌟 주요 특징

### 1. 3대 원격 프로토콜 완벽 통합
- **🖥️ VNC**: noVNC(`@novnc/novnc`) 코어 기반의 초경량 RFB 원격 데스크톱
- **🪟 RDP**: WebAssembly 기반 `ironrdp-wasm` 엔진을 탑재하여 별도 데몬 없이 Windows 원격 데스크톱을 브라우저에서 직접 초고속 렌더링
- **💻 SSH Terminal**: `xterm.js` + `ssh2` 기반의 풀 기능 웹 터미널
  - **인증 방식**: 일반 패스워드 로그인뿐만 아니라 **SSH 개인키(PEM / OpenSSH Private Key)** 및 **패스프레이즈** 완벽 지원
  - **시작 시 자동 실행 명령 (Initial Command)**: 접속 시 `tmux`, `screen`, `bash`, `htop` 등 지정 명령 자동 실행

### 2. 멀티 탭 워크스페이스 & 좌측 사이드바 패널
- **브라우저 탭 스타일 멀티 세션**: 여러 대의 서버 또는 동일 서버의 복수 세션을 탭 형태로 동시에 열어두고 전환하며 작업 가능
- **접이식 좌측 사이드바 패널**: 화면을 가리지 않고 자유롭게 열고 닫을 수 있는 서버 목록 네비게이션 패널
- **탭 우클릭 컨텍스트 메뉴**:
  - `📋 세션 복제 (새 탭으로 열기)`: 현재 서버를 새 탭으로 즉시 추가 접속
  - `🔄 세션 재연결 (이어받기)`: 연결이 끊겼거나 일시 오류 시 기존 세션 이어받기
  - `🆕 세션 새로 시작 (신규 접속)`: 기존 세션을 갱신하고 완전 신규 세션으로 접속
  - `✕ 탭 닫기 (세션 종료)`: 탭을 닫고 백엔드 원격 세션까지 안전하게 완전 종료
  - `🧹 다른 탭 모두 닫기`
- **SSH 터미널 폰트 크기 조절**: 상단 툴바의 `A-`, `A+` 버튼 및 `Ctrl`+`+`/`-` 단축키 지원 (브라우저 로컬 저장소 영속화)

### 3. 그룹(Group) 분류 & 태그(Tags) 시스템
- **대시보드 그룹 필터 바**: 서버 등록 시 입력한 그룹별로 상단에 `[전체]`, `[📁 운영]`, `[📁 개발]`, `[기타/미분류]` 필터 탭 바 자동 생성
- **뷰어 사이드바 접이식 아코디언**: 좌측 패널에서 서버들이 그룹별 아코디언 섹션(`▼ 📁 그룹명 (N)`)으로 깔끔하게 분류되어 접고 펼치기 지원
- **다중 `#태그` 뱃지**: 쉼표로 자유롭게 입력한 태그가 하늘색 뱃지로 표시되며, 클릭 시 검색창에 자동 입력되어 즉시 필터링
- **실시간 통합 검색**: 서버 이름, 호스트 IP/도메인, 설명뿐만 아니라 그룹명 및 태그명(`db`, `#linux`)으로도 실시간 검색

### 4. 지능형 세션 영속성 (Session Retention & Reattach)
- **새로고침(F5) / 브라우저 재실행 시 SSH 세션 유지**: 브라우저 창을 닫거나 새로고침해도 원격 SSH 세션과 512KB 스크롤백 기록이 백엔드에 유지되어 작업 상태 그대로 복원
- **명시적 탭 닫기 처리**: 사용자가 직접 탭의 `[×]`를 눌러 닫으면 백엔드 원격 프로세스까지 즉시 완전 종료(`terminate`)되어 미사용 세션이 남거나 새로고침 시 부활하지 않음
- **TUI/터미널 질의 시퀀스 필터링**: `vi`, `vim` 등 전체화면 프로그램 사용 후 세션 복원 시에도 단말 질의 응답 코드가 쉘 프롬프트로 누출되지 않도록 재생 중 응답 억제

### 5. 초경량 단일 컨테이너 (No Heavy Daemons)
- Apache Guacamole처럼 별도의 무거운 C 언어 데몬(`guacd`)을 띄울 필요 없이, **순수 Node.js 단일 프로세스**로 VNC, RDP, SSH 웹 프록시를 모두 처리 (단일 포트 `8080`)
- 외부 데이터베이스 없이 `/conf.d/remotehub/config.json` 단일 파일로 모든 설정이 저장되어 백업 및 이전이 간편

### 6. 편의 및 보안 기능
- **드래그 앤 드롭 순서 변경**: 메인 포털에서 카드 상단의 `▲` / `▼` 버튼 또는 마우스 드래그 앤 드롭으로 출력 순서 자유 정렬
- **실시간 포트 핑 (Healthcheck)**: 각 서버의 포트(5900, 3389, 22) 활성화 상태와 지연 시간(ms) 실시간 확인
- **선택적 보안 마스터 로그인**: 웹 포털 전체 접근을 보호하는 마스터 비밀번호 인증(ON/OFF) 내장

## 🚀 빠른 시작 (Docker Compose)

### 1. `docker-compose.yml` 실행
```bash
docker compose up -d --build
```

실행 후 브라우저에서 `http://localhost:8080`에 접속합니다.

```bash
# 로컬의 config 디렉터리를 /conf.d/remotehub로 마운트
docker run -d \
  --name remotehub \
  -p 8080:8080 \
  -v $(pwd)/config:/conf.d/remotehub \

  remotehub
```

## 운영 및 세션 유지 조건

- 세션 유지·출력 복원은 **SSH에만 적용**됩니다. 브라우저 연결이 끊긴 뒤 최대 24시간 유지하며, 컨테이너 또는 Node 프로세스를 재시작하면 종료됩니다. VNC/RDP는 재접속 시 새 연결을 생성합니다.
- SSH 출력 복원 중에만 터미널 자동응답 전송을 억제합니다. 정상 연결에서는 TUI가 요청하는 단말 응답을 그대로 전달합니다.
- 설정 파일이 손상되거나 스키마가 올바르지 않으면 실행 또는 API/WebSocket 접근을 차단합니다. 원본 파일을 복구한 후 다시 접속하세요. 설정 저장 시 비밀번호·개인키를 포함하므로 설정 디렉터리와 백업의 접근 권한을 제한하세요.
- `SESSION_SECRET`을 생략하면 설정 디렉터리에 권한 `0600`의 `.session-secret`을 자동 생성하고 재사용합니다. 설정 디렉터리와 함께 보관하세요. 여러 인스턴스를 운영한다면 동일한 비밀값과 별도의 공유 세션 저장소가 필요합니다.
- HTTPS 역방향 프록시 뒤에서는 `TRUST_PROXY`를 실제 신뢰 프록시 IP/CIDR에 맞춰 설정하세요. 애플리케이션으로의 직접 외부 접근은 제한해야 합니다.
- 로그인은 접속 IP별 15분 동안 10회로 제한됩니다. 인증 설정 변경에는 기존 마스터 비밀번호가 필요합니다.

### SSH/RDP 서버 신원 확인

SSH 호스트 키와 RDP TLS 인증서는 **최초 접속 신뢰(TOFU)** 방식으로 확인합니다. 첫 접속 때 SHA-256 지문을 서버 설정의 `sshHostKeyFingerprint` 또는 `rdpCertificateFingerprint`에 저장하고, 이후 달라지면 접속을 차단합니다. 최초 접속은 신뢰할 수 있는 네트워크에서 수행하세요. 미리 검증한 지문을 설정 파일에 입력하면 첫 접속부터 고정할 수 있습니다. SSH 값은 호스트 공개키 바이너리의 SHA-256 16진수, RDP 값은 인증서 DER의 SHA-256 16진수입니다.

서버 키 또는 인증서를 교체했다면 외부 경로로 새 지문을 확인한 뒤 설정 파일의 해당 값을 갱신하세요. 호스트·포트·프로토콜 변경 시 기존 지문은 초기화됩니다. SSH 개인키와 패스프레이즈는 브라우저 API로 반환하지 않으며, VNC/RDP 비밀번호는 브라우저 클라이언트 인증을 위해 접속 API에만 포함됩니다.

### 검증

`npm test`는 설정 손상, 입력 검증, 비밀값 마스킹, 인증 제한, SSH 세션 연결·복원·만료·종료, 실제 루프백 SSH 셸과 RDP X.224/TLS 핸드셰이크, 잘못된 핸드셰이크 입력, 로그아웃·비밀번호 변경 시 연결 인증 해제를 검증합니다. RDP TLS 테스트에는 `openssl` 실행 파일이 필요합니다. Chromium이 `/usr/bin/chromium`에 있거나 `CHROMIUM_PATH`로 지정되면 실제 브라우저의 SSH 단말 응답·새로고침 복원·탭 종료, 루프백 VNC 화면 렌더링, 프로토콜 변경 후 재연결, 초기화 중 탭 닫기, 모바일 입력·대화상자·필터 정렬도 검증하며, 브라우저가 없으면 해당 테스트를 건너뜁니다. 실제 Windows의 NLA/도메인 로그인과 화면·입력은 별도 환경에서 확인해야 합니다.

### 화면 조작

좁은 화면에서는 뷰어의 ☰ 버튼으로 서버 목록을 열고, 창 맞춤·클립보드·글꼴·전체화면은 `더보기`에서 조작합니다. 서버 카드의 `⋯` 메뉴에서 수정·정렬·삭제 및 실행 중인 SSH 세션 종료를 수행합니다. 검색·그룹 필터 중 ▲▼ 정렬은 표시된 서버끼리 순서를 교환합니다. `이전에 열었던 탭`은 접속 기록이며 실행 중인 SSH 세션과 구분됩니다. 대시보드의 `상태 새로고침`으로 포트 응답과 세션 상태를 다시 확인할 수 있습니다. 대화상자는 Tab 이동·Esc 닫기를 지원하고, 세션 탭은 방향키·Home/End로 이동하고 Delete로 종료할 수 있습니다.

### 모바일 원격 입력

- SSH 화면 아래 보조 키 바에서 Esc·Tab·방향키·Ctrl+C를 전송할 수 있습니다. `Ctrl`은 다음 한 문자에만 적용되며, `키보드`를 누르면 터미널 입력란으로 이동합니다. 보조 키 바는 가로로 스크롤할 수 있습니다.
- `더보기 → 세션 관리`에서 터치로 세션 복제·새로 시작·종료를 선택합니다. 탭 닫기는 백엔드 SSH 세션까지 종료합니다.
- RDP는 탭으로 클릭, 한 손가락 이동으로 드래그, 길게 누르기로 우클릭, 두 손가락 이동으로 스크롤합니다. `화면 이동 모드`에서는 원격 입력을 끄고, 창 맞춤을 끈 화면을 손가락으로 이동할 수 있습니다. 해상도는 `더보기`에서 변경합니다.
- RDP·VNC의 모바일 `텍스트 입력` 또는 클립보드의 `원격에 입력`으로 한글 등을 조합한 뒤 전송할 수 있습니다. RDP는 Unicode 키 입력으로 전달합니다. 클립보드 복사·지우기는 `기타 동작`에 있습니다.
- 가상 키보드가 열리면 Visual Viewport 크기에 맞춰 작업 영역·입력 바·대화상자를 보정합니다. 화면 노치·홈 표시 영역도 고려합니다. 실제 iOS/Android 키보드와 Windows 원격 입력의 최종 호환성은 실기기에서 확인해야 합니다.

### 연결 및 배포 점검

로그아웃하면 해당 로그인으로 열린 원격 연결이 끊깁니다. 마스터 비밀번호 변경 시 다른 로그인과 연결도 인증을 다시 받아야 하며, 분리된 SSH 셸의 유지 정책은 동일합니다. SSH 연결 표시는 인증과 셸 준비가 끝난 뒤 활성화됩니다. 대시보드·뷰어 API 요청에는 15초 제한이 있고, 원격 데스크톱 연결 실패 시 화면 안에서 재연결할 수 있습니다.

Docker 이미지는 `/api/status` 기반 상태 점검을 포함하며, 빌드 컨텍스트에서 로컬 설정·개인키를 포함할 수 있는 `config` 디렉터리와 `.env` 파일을 제외합니다. Podman을 직접 사용한다면 `podman build --format docker -t remotehub .`로 빌드해야 이미지의 HEALTHCHECK가 유지됩니다.
